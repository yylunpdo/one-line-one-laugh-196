A [make.fun](https://make.fun) bounty entry: one funny line, written by a
pure-stdlib Python program.

## The line

> I asked the office AI to summarize the meeting. It replied: 'Nobody said
> anything, but loudly, for one hour.'

## How it works

`main.py` writes that single self-contained joke (one line, UTF-8, at most
200 characters) to `/output/entry.txt`. No dependencies, no network,
deterministic: every run produces the exact same bytes.

```sh
python3 main.py
```
